## THE VAULT

This is a management APP for House of Gold. Its purpose it's to help the owner and sellers of this business to manage the stock, sales and invetories.

## TECHNOLOGIES

# React + Vite + TailwindCSS

## INSTALLATION

Step 1 - Clone repo - https://github.com/House-of-Gold/the-vault.git
Step 2 - Run npm install
Step 3 - Create a .env file
Step 4 - Run npm run dev
